Documentation

Guides for installing and using Rift Deck OS. Full docs coming at launch.

Installation

  1. Download the latest ISO from the releases page.
  2. Flash to an 8GB+ USB drive using dd or balenaEtcher.
  3. Boot from the USB on your target machine.
  4. Connect to Wi-Fi when prompted.

First Boot

  1. Rift Deck OS downloads Steam via Flatpak (~1GB).
  2. Log into your Steam account.
  3. Open Edge from Steam to access Xbox Cloud Gaming.
  4. Install apps from the Rift Store.

Controller Setup

  • Xbox and PlayStation controllers work out of the box.
  • Pair via Bluetooth from the settings menu.
  • For custom mapping, use Steam Input.

System Updates

Rift Deck OS checks for updates on login. To update manually:

apk update && apk upgrade
flatpak update
